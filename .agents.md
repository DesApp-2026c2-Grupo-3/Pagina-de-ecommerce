# Agents — Contexto del Proyecto

## Objetivo del sistema

Plataforma web de delivery para cadena de comida rápida (análoga a McDonald's / Burger King).
Tres aplicaciones comparten una misma base de datos: app de clientes, sistema administrativo y (opcional) app de repartidores.
Proceso completo: configuración de productos, catálogo, pedidos y entrega.

## Reglas de negocio clave

- Autenticación JWT con roles `cliente` / `administrador`. El sistema nace con un administrador inicial (seed).
- Los administradores pueden crear nuevos administradores.
- La sucursal que prepara un pedido se asigna automáticamente: más cercana, activa y con stock suficiente; si ninguna la cubre, el cliente elige entre las disponibles.
- El carrito vive en el cliente (localStorage) y se envía completo al servidor al confirmar el pedido.
- Flujo de estados del pedido: Pendiente → Confirmado → En preparación → Listo para entregar → En camino → Entregado / Cancelado.
- Cada producto puede tener configuraciones especiales: ingredientes adicionales/eliminados, tamaños, sabores.
- Los datos de cada pedido registrado incluyen: cliente, sucursal asignada, dirección de entrega, fecha/hora, detalle de productos, importe y estado inicial.
- El cliente puede consultar su historial de pedidos con detalle, importe, fecha y estado final.
- El sistema administrativo ofrece ABM (CRUD) de: Productos, Categorías, Promociones, Sucursales, Stock, Administradores, Estados generales y Parámetros del sistema.
- Reportes requeridos: productos más vendidos, menos vendidos, sin stock, mayor facturación.

## Entidades principales / Modelo

- **Usuarios** — clientes y administradores (con rol).
- **Direcciones** — direcciones de entrega asociadas a usuarios.
- **Sucursales** — locales físicos con nombre, dirección, lat/lng, horarios, teléfono y estado (activa/inactiva).
- **Categorías** — agrupan productos (ej: Hamburguesas, Bebidas, Postres).
- **Productos** — nombre, descripción, categoría, precio, imagen, estado (disponible/no disponible).
- **ConfiguracionesProducto** — opciones especiales por producto (ingredientes, tamaños, sabores).
- **Stock** — disponibilidad de producto por sucursal.
- **Promociones** — ofertas y descuentos aplicables.
- **Pedidos** — registro de cada pedido con cliente, sucursal, dirección, fecha/hora, importe y estado.
- **DetallePedidos** — ítems del pedido (producto, cantidad, observaciones, configuraciones, subimporte).
- **HistorialEstados** — registro de cada cambio de estado de un pedido con fecha/hora.
- **EstadosGenerales** — estados disponibles del flujo de pedidos.
- **Parametros** — configuraciones generales del sistema.

## Estilos / Diseño (Frontend)

Stack: React 19 + Vite + TypeScript, estilos con **Tailwind CSS v4** (plugin `@tailwindcss/vite`), sin React Router por ahora. Paleta y tokens definidos en `src/index.css` vía `@theme`.

- **Marca:** rojo `--color-brand-red: #e4002b`, fondo oscuro `--color-brand-dark: #1a1414`, crema `--color-brand-cream: #fff7e6`. Usar como `bg-brand-red`, `text-brand-dark`, etc.
- **Navbar:** `sticky top-0 z-20 bg-brand-dark shadow-md`; logo con círculo `grid place-items-center rounded-full bg-brand-red`; links `rounded-lg px-4 py-2 font-semibold hover:bg-brand-red`; CTA "Iniciar Sesión" `rounded-full bg-brand-red`. Menú hamburguesa con estado local en `md:hidden`.
- **Hero:** sección `bg-brand-red text-white`, contenedor `mx-auto max-w-7xl px-4 py-12`, título `text-4xl sm:text-5xl font-extrabold`, botones CTA `rounded-full bg-brand-dark` (primario) y `rounded-full border-2 border-white` (secundario).
- **Sección de categoría:** título `mb-6 flex items-center gap-3 text-2xl font-extrabold` con ícono; grid responsive `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 gap-6`.
- **ProductCard:** `rounded-2xl bg-white shadow-md hover:-translate-y-1 hover:shadow-xl transition-transform`, imagen `h-40 w-full object-cover`, precio `text-xl font-extrabold text-brand-red`, botón "Agregar" `rounded-full bg-brand-dark px-4 py-2 text-sm font-bold`.
- **Footer:** `mt-16 bg-brand-dark text-white`, textos secundarios `text-white/70`.
- **Precios:** formatear con `format`/`toLocaleString('es-AR')`.
- **Layout base:** `min-h-screen bg-brand-cream text-brand-dark`.
